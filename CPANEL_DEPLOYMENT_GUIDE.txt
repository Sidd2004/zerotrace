# How to Deploy ZeroTrace to cPanel from GitHub

Follow these steps to safely replace your old website with the new ZeroTrace platform on your cPanel hosting.

## Step 1: Build the Project Locally

Before uploading to cPanel, you need to create a production-ready "build" of your React app.

1. Open your terminal in the `zerotrace` folder.
2. Run the build command:
   ```bash
   npm run build
   ```
3. This will create a new folder named `dist` inside your project directory. This `dist` folder contains the final HTML, CSS, and optimized JavaScript files that your web server understands.

## Step 2: Prepare the Build for Upload

1. Open the `dist` folder on your computer.
2. Select all files inside the `dist` folder (do not select the `dist` folder itself, just its contents: `index.html`, the `assets` folder, etc.).
3. Zip these files together into an archive (e.g., `zerotrace_build.zip`).

## Step 3: Access File Manager in cPanel

1. Log in to your cPanel dashboard (usually `yourdomain.com/cpanel`).
2. Navigate to the **Files** section and click on **File Manager**.
3. In File Manager, go to your website's root directory. This is usually `public_html` for your primary domain (if it's an addon domain, go to that specific folder).

## Step 4: Backup and Remove the Old Website

It's crucial to remove the old files, especially if you had a different system (like WordPress) installed previously, to prevent conflicts.

1. **Backup (Recommended):** Select all existing files and folders in your `public_html`, click **Compress** from the top menu, create a `backup_old_site.zip`, and download it to your computer just in case.
2. **Delete Old Files:** Select all the files and folders currently in your `public_html` (except for system files like `cgi-bin` or your `backup_old_site.zip` if you left it there).
3. Click **Delete** from the top menu to clear the folder. Your `public_html` should now be mostly empty.

## Step 5: Upload the New ZeroTrace Build

1. Still inside `public_html`, click the **Upload** button in the top menu.
2. Select the `zerotrace_build.zip` file you created in Step 2 from your computer.
3. Wait for the upload to reach 100% and turn green.
4. Go back to the File Manager view of your `public_html` folder. (You may need to click 'Reload' if you don't see the zip file).
5. Right-click on `zerotrace_build.zip` and select **Extract** (or select it and click Extract on the top menu). Extract it directly into `public_html`.
6. You should now see `index.html`, the `assets` folder, etc., sitting directly inside `public_html`.
7. You can now delete the `zerotrace_build.zip` file from the server to save space.

## Step 6: Configure Routing (CRITICAL for React Apps)

Because ZeroTrace is a React Single Page Application (SPA), the server needs to know how to handle URLs like `/community` or `/contact`. Without this step, refreshing any page other than the homepage will result in a 404 Error.

1. In File Manager, ensure you have **Show Hidden Files (dotfiles)** enabled (go to Settings in the top right corner checking the box).
2. Look for a file named `.htaccess` in your `public_html` folder.
   - If it exists, select it, right-click, and choose **Edit**.
   - If it doesn't exist, click **+ File** in the top-left, name it exactly `.htaccess`, and then edit it.
3. Replace the contents of the `.htaccess` file with the following code (or paste it at the bottom if you know what you are doing):

```apache
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  RewriteRule ^index\.html$ - [L]
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>
```

4. Click **Save Changes**.

## Step 7: Verify the Deployment

1. Open a web browser and visit your domain (e.g., `https://yourdomain.com`).
2. You should see the new ZeroTrace homepage.
3. Click through the links (Services, Community, Contact) and try refreshing the page on those routes to ensure the `.htaccess` rule is working correctly.

**Congratulations, your new website is live!**
